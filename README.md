# plebian-apt

Apt repository for [Plebian-OS](https://github.com/itsmygithubacct/plebian-os)
packages.

**Status: hosting test.** The repository currently holds one dummy package,
`plebian-apt-spike`, signed with a throwaway test key. It exists to check that
apt can install from GitHub Pages and from GitHub release assets. Do not add
it to a real system's sources; nothing here is a Plebian-OS release, and the
test key will be replaced.

The published tree is on the `gh-pages` branch.
